## Performance tasks

- **data_response** — A mapwork task (10 marks): a map extract given as a markdown grid of squares with their features, heights and a scale, and 1-mark parts on the key, a six-figure grid reference, a compass direction and a bearing, a distance along a route, a height difference, relief and drainage.
- **data_response** — A second mapwork task (10 marks) on a different landscape (upland and river if the first was coastal or urban), with a cross-section described point by point and settlement pattern and communications.
- **data_response** — A graph and table task (8 marks): data from one theme to plot on the learner's own paper, a trend to describe with figures, a calculation, and a reason to suggest.
- **data_response** — A photograph and diagram task (6 marks): a described photograph or field sketch of a landscape to describe, with features to identify and a reason to suggest.
- **data_response** — A third mapwork task (10 marks) on an urban or coastal extract: land use, urban morphology, services and functions of settlements, communications, with grid references and bearings.
- **data_response** — A second graph and table task (8 marks) on a different graph type (a population pyramid, a climate graph, a triangular or scatter graph): read values, describe the pattern, calculate a range or percentage, suggest a reason.
- **data_response** — A third graph and table task (8 marks) on a map-based resource (a choropleth map, a flow diagram or a dispersion graph): extract information, describe the distribution, suggest a suitable graph for data given.
- **data_response** — A fourth mapwork task (10 marks) on a rural extract: drainage density and stream patterns, relief described with suitable terms, a route distance, a bearing, and inferences about land use from the map evidence.

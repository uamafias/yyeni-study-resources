# Namibia NSSCAS Mathematics 8227 Workbench

Vitalis selected Grade 12 NSSCAS Mathematics as the active framework pilot on
15 November 2026. The scope is whole-syllabus problem-type mapping, followed by
incremental recipe authoring and local application validation. The syllabus is
the NIED December 2020 edition, implementation/first examination 2021; the current
official index links to a file identical to the existing local copy.

Follow the existing [Workbench playbook](../../workbench/playbook/README.md),
not the Flashcard Studio authoring/import pipeline. The common framework remains
subject-neutral. An advanced Maths pilot can expose demanding requirements but
does not by itself validate younger-learner pedagogy or Physics transfer.

Resume from [Workbench STATUS](workbench/STATUS.md) and its source inventory.
Original papers/syllabus stay in existing shared source folders; the user-supplied
textbook and NIED catalogue are under `sources/namibia/nsscas/8227-mathematics/`.
The year in this workspace name records the project year, not a new syllabus edition.

## Branch1: graph-intercept

Model is y=Ae^(px+p), A>0. Exact canonical model choices L=ln A in{-1,0,1,2,3}; p in{-3/4,-1/2,-1/4,1/4,1/2,3/4}. Two displayed coordinates on the graph (x,ln y) use x1 in{1,2,3}, x2=x1+d, d in{1,2,3}; ordinate at each is p*x+p+L. The problem asks A to3 significant figures and p exactly, with working. Stated coordinate labels are exact. There are30 underlying models and270 coordinate presentations. No-repeat uses the30 model identities; choosing another coordinate pair for a used model is not counted as new practice capacity. These choices vary growth/decay, positive/negative log ordinates and the coupling of slope with intercept, while preserving the same reasoning.

Diagram spec, R3-07: learner **must read** horizontal axis x, vertical axis ln y, exact labelled coordinates (x1,u1),(x2,u2), and which two points lie on the same straight line. Do not relabel the ordinate y or treat u as y. Fixed: Cartesian axes, straight transformed relationship, explicit ln symbol, schematic 'not to scale' status if no grid. Variable: model p,L, point coordinates, line direction and viewing bounds. Relations: u_i=p*x_i+p+L, x2>x1; both points lie exactly on the rendered line; view includes negative ordinates when present and all labels; neither positive y nor an A-value is inferred from the screen scale. Accessibility text supplies the same labelled givens, not the hidden parameter values. Do not put A or p into alt text. No learner sketch is required. Correctly generated source-dependent asset and visual marker capabilities remain runtime checks.

Solution: ln y=px+p+ln A. Compute m=(u2-u1)/(x2-x1)=p. Compute intercept b=u1-p*x1. Then ln A=b-p and A=exp(b-p), rounding only the final A. Independent oracle substitutes recovered A,p into **both original exponential values**, not merely into the same logarithmic answer formula.

Memo5: G-B1 for correct transformed line; G-M1 for a correct gradient calculation identified as p; G-A1 for correct p; G-M2 (dependent on coherent p or two-coordinate alternative) for substituting a labelled point with the **additional+p** and isolating ln A; G-A2 for correct A to3sf or an exact equivalent. No official FT is imported where not stated. Proposed G-M2 may follow a consistent nonzero p slip for method only; G-A1/G-A2 remain correct-answer awards. Correct two-equation simultaneous recovery has the same5-mark cap. Final correct numeric A,p alone earns the two accuracy awards; the transformed line can imply G-B1 only when actually present; unseen gradient/substitution methods are not awarded. No double credit for both methods.

## Branch2: gradient-target

Model y=b^(c*a)*a^x; b in{2,3}, c in{1,2}. The graph of log_b y against x has stated gradient m in{1,2}. Target y=b^q, q in{0,1,2,3,4}. Then a=b^m, so2<=a<=9 and c*a<=18. All40 tuples(b,c,m,q) are admitted and distinct with these prime bases; exact target1 at q0 is allowed. The question asks (a) exact a and (b) hence exact x when y is the supplied target. Negative x is allowed; this is not an elapsed-time context. No giant numerical power needs evaluating.

Given representation text, not a fake graph image: must read stated log base b, which variable is plotted on each axis, gradient m, the model factor b^(c*a), and target y. Fixed: transformed ordinate log_b y, x abscissa, positive a not1. Variable: b,c,m,q. Constraints: b>0,b!=1,a=b^m>1, y>0; same a used in both parts. A later diagram must show that exact base and slope and must not expose hidden a in labels. Do not conflate c*a with a^c or omit the prefactor.

Solution log_b y=c*a+x log_b a. Thus log_b a=m and a=b^m. Substitute y=b^q: q=c*a+m*x, so x=(q-c*a)/m. A direct index-law solution replacing a by b^m and equating powers is equally valid. No change-of-base identity is required. Independently substitute x into b^(c*a)*a^x and check the exact target.

Memo3+2: T-B1 correct transformed line, T-M1 log_b a=m identified, T-A1 exact a; U-M1FT substitute their positive a!=1 and given target into either valid original/log equation; U-A1 correct x. Cue edge t-parameter→t-target ('hence'); distinct FT edge applies only to U-M1. Unit/negative a cannot receive the log FT method as if defined. A self-consistent original-equation alternative gets U-M1 but no second method award. Final a alone may earn T-A1, not an invented unseen log-line derivation; final x alone earns U-A1. Complete exact a with correct line can imply T-M1 where the displayed coefficient equality proves it; no blanket numerical working policy.

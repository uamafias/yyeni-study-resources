### Equivalent forward proofs and later own-result substitution (D2)

**CALC-D2-DEV09** maps valid equivalent-relation proofs into the same four slots, rather than giving a generic maximum with no award mapping. The justified root/y identity belongs in S3 only on the explicit-root route. Dividing by y is valid because every admitted C is nonzero, so no point on the curve has y=0. Write $ae^{kx}+y=C/y$; differentiate to $ake^{kx}+y'=-Cy'/y^2$ (S1/S2/S3), solve for $y'=-ake^{kx}y^2/(y^2+C)$, then substitute $C=ae^{kx}y+y^2$ and cancel the nonzero y to establish the target (S4). A log route uses $\ln a+kx=\ln|C-y^2|-\ln|y|$; all log arguments are absolute values where required, since the supplied y values are negative. Differentiating gives $k=-2yy'/(C-y^2)-y'/y$ (S1/S2/S3), then the same forward rearrangement/back-substitution earns S4. At the supplied negative-y branch, writing $\ln y$ without moduli is an invalid real relation: S1=0, dependent S2=0 and S4=0; independently correct remaining implicit derivative/constant evidence may earn S3=1, otherwise S3=0. Thus the maximum for that invalid route is **1/4**, not full proof credit. This is a proposed deterministic marking clarification (CALC-D2-DEV09 (D3 clarification)), pending confirmation and owner approval. The valid absolute-value route can earn4/4. A correct divided/log differentiation followed by failed or missing back-substitution earns **S1/S2/S3=3/4**, with S4=0; that step never costs S3 as well.

Simplifying a displayed target earns S4 when its equivalence is shown, for example by cancelling a common nonzero factor 2. There is no requirement to copy an unsimplified expression. A compensating error followed by a copied target still earns no S4.

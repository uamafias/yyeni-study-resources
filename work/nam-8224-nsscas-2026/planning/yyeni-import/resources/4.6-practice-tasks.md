# 4.6 Carbonyl compounds — practice tasks and worked answers



## ITEM-8224-4.6-P01

4 marks · Bloom: Apply

Identify the correct option in each question (1 mark each).
1. Name CH3CH2CHO. A propanal; B propanone; C ethanal; D propan-1-ol
2. Identify the molecular count of CH3COCH3. A C3H8O; B C3H6O; C C2H4O; D C3H6O2
3. Identify the carbonyl structure of a ketone. A CH3CH2OH; B CH3CHO; C CH3COCH3; D CH3COOH
4. Identify the product of controlled propan-2-ol oxidation with warm acidified dichromate(VI). A propanal; B ethanal; C propane; D propanone



### Worked answer

1. Key/correct option A. A includes the aldehyde carbon; B changes attachments, C misses a carbon and D changes C=O to C–OH. Each distractor represents the stated error.
2. Key/correct option B. B counts two CH3 and one carbonyl C/O; A adds two H, C omits carbon and D adds oxygen. Each distractor represents the stated error.
3. Key/correct option C. C has two carbon attachments at C=O; A is alcohol, B aldehyde and D acid. Each distractor represents the stated error.
4. Key/correct option D. D is the matching ketone; A changes carbonyl position, B loses carbon and C removes oxygen. Each distractor represents the stated error.

Required answer parts: key, correct option, distractor, error. Use the specific chemically correct points in the canonical answer; award no additional credit for repetition.

## ITEM-8224-4.6-P03

5 marks · Bloom: Apply

Calculate the maximum mass of carbonyl product from complete oxidation of 3.00 g propan-2-ol with warm acidified dichromate(VI). Name and represent the product, and give its molecular composition. Mr(propan-2-ol)=60.0; Ar(C)=12.0, Ar(H)=1.0, Ar(O)=16.0. [5]



### Worked answer

Propanone, CH3C(=O)CH3, C3H6O [1]. Equation: CH3CH(OH)CH3 + [O] → CH3COCH3 + H2O [1]. Working: n(alcohol)=3.00/60.0=0.0500 mol [1]; ratio1:1 gives0.0500 mol product and Mr=58.0 [1]; m=0.0500×58.0=2.90 g [1]. Answer to three significant figures; masses already g so no prefix conversion needed. This is a theoretical maximum, not an observed isolated yield.

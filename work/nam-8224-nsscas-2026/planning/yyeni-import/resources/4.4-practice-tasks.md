# 4.4 Hydroxyl compounds — practice tasks and worked answers



## ITEM-8224-4.4-P01

6 marks · Bloom: Apply

Identify the correct option in each question (1 mark each).
1. Name CH3CH(OH)CH3. A propan-2-ol; B propan-1-ol; C ethanol; D propanone
2. Identify the gas formed by sodium reacting with ethanol. A oxygen; B hydrogen; C carbon dioxide; D ethene
3. Identify the controlled primary oxidation product of ethanol. A ethene; B propanone; C ethanal; D methanoic acid
4. Name CH3CH2CH2CH2OH. A butan-2-ol; B propan-1-ol; C butanal; D butan-1-ol
5. Identify the appropriate conventional acid preparation for ethanol to ethene. A concentrated sulfuric acid and strong heating; B dilute acid at room temperature; C aqueous hydroxide; D cold hydrogen without catalyst
6. Identify the ester from ethanol plus ethanoic acid under heated acid-catalysed esterification at fixed temperature. A methyl propanoate; B ethyl ethanoate; C ethanal; D sodium ethoxide



### Worked answer

1. Key/correct option A. A locates OH at carbon2; B moves it, C loses carbon and D changes functional group. Each distractor represents the stated error.
2. Key/correct option B. Hydrogen is released from O–H; oxygen and CO2 are not products, and ethene requires dehydration. Each distractor represents the stated error.
3. Key/correct option C. Ethanal retains two carbons and is the aldehyde; A is dehydration, B has the wrong carbon count/class and D loses carbon. Each distractor represents the stated error.
4. Key/correct option D. D matches terminal OH in a four-carbon chain; A changes position, B loses carbon and C changes family. Each distractor represents the stated error.
5. Key/correct option A. A supplies dehydration settings; B does not, C is not that reagent and D is not alcohol dehydration. Each distractor represents the stated error.
6. Key/correct option B. B uses the ethanol alkyl and ethanoic-acid acid portion; A changes connections, C is oxidation and D arises with sodium. Each distractor represents the stated error.

## ITEM-8224-4.4-P03

5 marks · Bloom: Apply

Calculate the maximum hydrogen amount, in mol, from 4.60 g of the saturated two-carbon monohydric alcohol reacting completely with excess sodium. Name the alcohol and give its structural condensed and molecular representations. Use Ar(C)=12.0, Ar(H)=1.0, Ar(O)=16.0. [5]



### Worked answer

Ethanol, CH3CH2OH, C2H6O [1]. Equation: 2CH3CH2OH + 2Na → 2CH3CH2O−Na+ + H2 [1]. Working: Mr=2(12.0)+6(1.0)+16.0=46.0; n(ethanol)=4.60/46.0=0.100 mol [1]. Ratio2:1 gives n(H2)=0.100/2 [1]; answer0.0500 mol [1], three significant figures. Mass already g, no prefix conversion needed; hydrogen amount is not a gas volume.

# 4.7 Carboxylic acids and derivatives — practice tasks and worked answers



## ITEM-8224-4.7-P01

7 marks · Bloom: Apply

Identify the correct option in each question (1 mark each).
1. Name HCOOH. A methanoic acid; B ethanoic acid; C methanol; D methanal
2. Name CH3CH2COOH. A ethanoic acid; B propanoic acid; C butanoic acid; D propanal
3. Name CH3COOCH3. A ethyl methanoate; B methyl propanoate; C methyl ethanoate; D ethanoic acid
4. Identify the syllabus name of CH3CH(NH2)CH2CH3. A 1-aminobutane; B 2-aminopropane; C butan-2-ol; D 2-aminobutane
5. Name CH3CH2COOCH2CH3. A ethyl propanoate; B propyl ethanoate; C methyl butanoate; D ethyl ethanoate
6. Name CH3(CH2)4COOH. A pentanoic acid; B hexanoic acid; C butanoic acid; D hexanol
7. Identify the name of CH3CH2NH2. A ethanol; B ethanamide; C ethanamine; D propanamine



### Worked answer

1. Key/correct option A. A has one acid carbon; B adds carbon, C loses carbonyl and D loses acid OH. Each distractor represents the specified error.
2. Key/correct option B. B includes the acid carbon; A omits it, C adds one and D changes functional group. Each distractor represents the specified error.
3. Key/correct option C. C correctly names both sides; A swaps their counts, B adds acid carbon and D loses the ester alkyl group. Each distractor represents the specified error.
4. Key/correct option D. D preserves four carbons and NH2 position; A moves it, B loses carbon and C changes the group. Each distractor represents the specified error.
5. Key/correct option A. A identifies ethyl on O and propanoate on the carbonyl side; B/C change connectivity and D misses a carbon. Each distractor represents the specified error.
6. Key/correct option B. B counts methyl plus four CH2 plus carboxyl carbon; A/C undercount and D changes family. Each distractor represents the specified error.
7. Key/correct option C. C describes two carbons and NH2; A changes heteroatom, B adds a carbonyl group and D adds carbon. Each distractor represents the specified error.

## ITEM-8224-4.7-P03

5 marks · Bloom: Apply

Calculate the maximum acid mass from complete oxidation of 2.30 g ethanol with excess acidified dichromate(VI) under reflux. Name the product, draw its carboxyl connection and give molecular composition. Mr(ethanol)=46.0; Ar(C)=12.0, Ar(H)=1.0, Ar(O)=16.0. [5]



### Worked answer

Ethanoic acid, CH3C(=O)OH, C2H4O2 [1]. Equation: CH3CH2OH + 2[O] → CH3COOH + H2O [1]. Working: n(ethanol)=2.30/46.0=0.0500 mol [1]; ratio1:1 gives0.0500 mol acid, Mr=2(12.0)+4(1.0)+2(16.0)=60.0 [1]; m=0.0500×60.0=3.00 g [1]. Answer to three significant figures; masses already in g so no prefix conversion is needed.

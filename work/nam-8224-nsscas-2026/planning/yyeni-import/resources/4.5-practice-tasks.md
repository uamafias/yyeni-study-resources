# 4.5 Isomerism: structural and stereoisomerism — practice tasks and worked answers



## ITEM-8224-4.5-P01

5 marks · Bloom: Apply

Identify the correct option in each question (1 mark each).
1. Identify the number of open-chain alkane connectivities for C4H10. A 2; B 3; C 4; D 1
2. Identify the relationship between but-1-ene and but-2-ene. A optical; B positional structural; C identical after rotating paper; D different compositions
3. Identify the relationship between cis and trans but-2-ene. A chain structural; B functional-group structural; C geometrical stereoisomers; D different molecular counts
4. Identify why propene lacks a cis/trans pair. A it contains no double bond; B it is saturated; C its carbon count is odd; D one double-bond carbon has two identical H groups
5. Identify the open-chain alkene connectivity missing from but-1-ene and but-2-ene in a C4H8 list. A 2-methylpropene; B butane; C pent-1-ene; D ethanol



### Worked answer

1. Key/correct option A. Butane and2-methylpropane give2;3/4 duplicate or invent structures,1 omits branching. Each distractor represents the stated error.
2. Key/correct option B. B moves double-bond position; A wrongly keeps connectivity, C overlooks its position and D miscounts identical totals. Each distractor represents the stated error.
3. Key/correct option C. C preserves connections with different spatial arrangement; A/B change connections and D contradicts their equal counts. Each distractor represents the stated error.
4. Key/correct option D. D is the local attachment test; A/B are false and C is not the criterion. Each distractor represents the stated error.
5. Key/correct option A. A is the branched valid alkene; B/C/D have different counts or families. Each distractor represents the stated error.

## ITEM-8224-4.5-P03

5 marks · Bloom: Apply

Calculate how many distinct open-chain C4H8 alkene forms result when geometrical forms are counted separately. Give the structural connectivities, state their isomer relationships and account for whether each provides one or two spatial forms. [5]



### Worked answer

Three structural connectivities: but-1-ene [1], but-2-ene and branched2-methylpropene [1]. But-1-ene/but-2-ene are positional, while2-methylpropene changes the chain skeleton [1]. But-2-ene supplies cis/trans stereoisomers because each C=C carbon has H and CH3; the other two lack this pair [1]. Equation/working:1+2+1=4 distinct forms [1]. Answer is a count with no physical unit; counts are exact integers so significant-figure rounding is inapplicable. No mass or volume conversion is required.

## ITEM-8224-4.3-P01

6 marks · Bloom: Apply

Identify the correct option in each question (1 mark each).
1. Name CH3CH2CH2Cl. A 1-chloropropane; B 2-chloropropane; C 1-chlorobutane; D propene
2. Identify the gas region protected by ozone relevant to CFC depletion. A ground-level smog; B stratospheric ozone layer; C dissolved oxygen in water; D a fuel tank
3. Identify a structural approach removing a refrigerant chlorine-radical source. A increase chlorine content; B ignore structure; C use a suitable chlorine-free replacement; D make more CFC
4. Name CH3CHBrCH2CH3. A 1-bromobutane; B 3-bromobutane; C 2-bromopropane; D 2-bromobutane
5. Identify the supported conclusion if a CFC radical is regenerated in an ozone cycle. A it can react repeatedly; B it is permanently consumed in the first step; C it becomes a harmless final polymer; D ozone is unaffected
6. Identify the supported conclusion for a replacement containing C,H,F but no Cl. A it cannot warm the atmosphere; B it lacks a C–Cl chlorine source; C it instantly repairs existing ozone loss; D its lifetime is known numerically



### Worked answer

1. Key/correct option A. A matches three carbons and terminal Cl; B moves Cl, C adds carbon and D removes halogen and changes bonding. Each distractor reflects the specified error.
2. Key/correct option B. B is the protective ozone layer; A is a different ozone problem and C/D are unrelated locations. Each distractor reflects the specified error.
3. Key/correct option C. C removes its C–Cl source; A/D retain or increase that source and B supplies no chemical solution. Each distractor reflects the specified error.
4. Key/correct option D. D gives the correct four-carbon parent and lower locant; A moves Br, B misnumbers, C loses carbon. Each distractor reflects the specified error.
5. Key/correct option A. A follows regeneration; B contradicts it, C invents a product and D ignores net ozone loss. Each distractor reflects the specified error.
6. Key/correct option B. B follows composition; A/C overstate consequences and D requires measurements not given. Each distractor reflects the specified error.

## ITEM-8224-4.3-P02

8 marks · Bloom: Apply

Explain changes to a two-carbon saturated molecule bearing one Br.
(a) Draw its displayed structure and name it. [3]
(b) State its molecular composition. [1]
(c) Write its ionic reaction with heated aqueous hydroxide. [2]
(d) Explain why heated ethanolic cyanide gives a three-carbon organic product. [2]



### Worked answer

(a) Two single-bonded C atoms [1], three H on one and two H plus Br on the other [1], bromoethane [1]. (b) C2H5Br [1]. (c) CH3CH2Br + OH− → CH3CH2OH + Br−: organic change [1], correct ionic balance [1]. (d) Carbon of CN− bonds to the carbon losing Br [1]; its added carbon gives CH3CH2CN, propanenitrile [1]. ## ITEM-8224-4.3-P03

5 marks · Bloom: Apply

Calculate the maximum ethanol mass obtainable by complete hydrolysis of 5.45 g of the saturated two-carbon monobromo compound. Name and represent that reactant. Use Ar(C)=12.0, Ar(H)=1.0, Ar(Br)=79.9 and Mr(ethanol)=46.0. [5]



### Worked answer

Bromoethane, CH3CH2Br, molecular composition C2H5Br [1]. Equation: CH3CH2Br + OH− → CH3CH2OH + Br− [1], so mole ratio1:1. Working: Mr(bromoethane)=2(12.0)+5(1.0)+79.9=108.9; n=5.45/108.9=0.0500459 mol [1]. Ethanol n=0.0500459 mol [1]; m=0.0500459×46.0=2.30211 g, answer2.30 g to three significant figures [1]. Mass units already g; retain unrounded intermediate values.

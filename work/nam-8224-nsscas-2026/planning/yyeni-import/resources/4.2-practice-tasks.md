# 4.2 Hydrocarbons — practice tasks and worked answers



## ITEM-8224-4.2-P01

12 marks · Bloom: Apply

Identify the correct option for each question (1 mark each).
1. Name the one-carbon alkane. A methane; B ethane; C propane; D butane
2. Name the five-carbon straight-chain alkane. A butane; B pentane; C hexane; D propene
3. Name CH2=CH2. A ethane; B propene; C ethene; D but-1-ene
4. Name CH3CH=CHCH3. A but-1-ene; B propene; C butane; D but-2-ene
5. Identify the name of an alkane methyl substituent. A methyl; B ethene; C hydroxy; D chloro
6. Identify the suffix used for a simple alkene. A –ane; B –ene; C –ol; D –oic acid
7. Name CH3CH(CH3)CH2CH3. A 3-methylbutane; B pentane; C 2-methylbutane; D 2-methylpentane
8. Name CH3C(CH3)2CH2CH2CH2CH3. A 2-methylhexane; B 2,2-dimethylpentane; C 5,5-dimethylhexane; D 2,2-dimethylhexane
9. Name CH2=CHCH2CH2CH3. A pent-1-ene; B pent-4-ene; C hex-1-ene; D pentane
10. Name CH2=C(CH3)CH2CH3. A 2-methylbutane; B 2-methylbut-1-ene; C 3-methylbut-3-ene; D pent-1-ene
11. Name CH3CH2CH=CHCH2CH3. A hex-1-ene; B hex-2-ene; C hex-3-ene; D pent-2-ene
12. Name CH3CH(CH3)CH(CH3)CH3. A 2,2-dimethylbutane; B 2-methylpentane; C 3,4-dimethylbutane; D 2,3-dimethylbutane



### Worked answer

1. Key/correct option A. Methane has one carbon; ethane, propane and butane have two, three and four respectively. Each distractor identifies the stated naming error.
2. Key/correct option B. Pentane has five carbons; butane has four, hexane six, and propene is a three-carbon alkene. Each distractor identifies the stated naming error.
3. Key/correct option C. Ethene has two carbons and C=C; ethane lacks C=C, propene has three carbons, and but-1-ene has four. Each distractor identifies the stated naming error.
4. Key/correct option D. But-2-ene has the internal double bond; but-1-ene places it terminally, propene has three carbons and butane is saturated. Each distractor identifies the stated naming error.
5. Key/correct option A. Methyl denotes –CH3; ethene names a molecule, hydroxy denotes OH and chloro denotes Cl. Each distractor identifies the stated naming error.
6. Key/correct option B. –ene indicates C=C; –ane, –ol and –oic acid identify alkane, alcohol and acid families. Each distractor identifies the stated naming error.
7. Key/correct option C. 2-methylbutane has the correct four-carbon parent and lowest locant; A numbers from the wrong end, B loses branching and D adds a parent carbon. Each distractor identifies the stated naming error.
8. Key/correct option D. D preserves the six-carbon parent and two branches; A loses one branch, B shortens the parent and C uses higher locants. Each distractor identifies the stated naming error.
9. Key/correct option A. A uses five carbons and the lowest double-bond locant; B reverses numbering, C adds carbon and D omits unsaturation. Each distractor identifies the stated naming error.
10. Key/correct option B. B preserves the branch and terminal C=C; A loses the double bond, C uses incorrect numbering and D loses branching. Each distractor identifies the stated naming error.
11. Key/correct option C. C locates C=C between carbons3 and4 of six; A/B move it and D changes carbon count. Each distractor identifies the stated naming error.
12. Key/correct option D. D gives two methyl branches at2 and3 of a four-carbon parent; A changes branching, B changes connectivity and C does not use lowest locants. Each distractor identifies the stated naming error.

## ITEM-8224-4.2-P02

8 marks · Bloom: Apply

Explain the ordinary ionic addition of HBr to propene and related alkene reactions.
(a) Write the major organic product and name it. [2]
(b) Explain the first-step pair movements and intermediate. [3]
(c) Describe the final electron-pair movement. [1]
(d) Write the organic products of hot, concentrated, acidified manganate(VII) cleavage of propene. [2]



### Worked answer

(a) CH3CHBrCH3 [1], 2-bromopropane [1].
(b) C=C pair to H of HBr [1]; H–Br pair to Br [1]; secondary CH3CH+CH3 and Br− formed [1].
(c) Bromide lone pair to positive carbon forms C–Br [1].
(d) CH3COOH [1] and CO2, with water in the full organic oxidation balance [1]. These are creditworthy points for each stated part; total8 marks.

## ITEM-8224-4.2-P03

5 marks · Bloom: Apply

Calculate the atom counts and Mr of CH3C(CH3)2CH2CH3, using Ar(C)=12.0 and Ar(H)=1.0. Then name this open-chain alkane and explain why it does not undergo rapid ionic bromine addition without radical-initiating light. [5]



### Worked answer

Equation/check: CnH2n+2 with n=6 gives H14. Working: four CH3, one CH2 and one C give C6H14 [1]; Mr =6(12.0)+14(1.0)=86.0 [1]. Mr has no unit; three significant figures match the supplied atomic masses. Name: 2,2-dimethylbutane [1]. Its strong, nearly non-polar C–C/C–H bonds [1] and absence of an electron-rich C=C pair [1] explain resistance to this ionic addition pathway. Counts are exact integers; no mass conversion is needed.

Required answer parts: equation, working, answer, unit, significant figures. Use the specific chemically correct points in the canonical answer; award no additional credit for repetition.

# Chemistry 8224 authoring reference pack

The governing syllabus and approved work orders are unchanged. The original 2025 examiner report has been recovered from NIED with the exact original hash. No assessment evidence was reclassified.

## How to use this pack

Search the local `.txt` files, then inspect the cited PDF page or HTML section. Record source ID plus page/section on every claim. The following routes help find material; they do not mark claims verified. Respect each topic’s exclusions and create original explanations, examples and figures.

OpenStax Chemistry: 2015 edition, 2017 revision, 1,355 PDF pages. It is not Chemistry 2e. Use the separately archived current Chemistry 2e §3.1 for the modern mole definition. The 222-page Organic Chemistry Tenth Edition study guide supplements the 40 archived textbook sections. Both books cover material outside NSSCAS; consult the syllabus first.

## Provenance and limits

`references.json` records original URLs, paths, SHA-256 hashes, extraction checks and topic/objective routes. Acquisition attempts, including failed superseded PDF links, are recorded by the shared harvester. The two `*-publisher.html` files are discovery shells and are excluded from the usable-source inventory.

Missing official mark schemes and older examiner reports remain documented evidence limitations. Source availability does not turn generated claims into verified claims.

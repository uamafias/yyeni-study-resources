- **practical_task** — A 20-mark thermometric or enthalpy task with original data, calculation, conclusion, uncertainty and improvement.
- **practical_task** — A 20-mark rates or gravimetric task with original data, a graph or linear treatment, calculation, conclusion, uncertainty and improvement.
- **practical_task** — A 20-mark qualitative-analysis task requiring precise observations, use of excess reagent where relevant, deductions and confirmatory tests using supplied notes.
- **practical_task** — A 20-mark planning and evaluation task covering apparatus, control variables, error, uncertainty, realistic improvements and an extension.

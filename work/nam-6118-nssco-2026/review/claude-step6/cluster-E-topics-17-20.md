### Topic 20 (listed first because it contains the only S1)

1. [T20][S1] ITEM-6118-20-P03 (practical_task, 16 marks), canonical_answer "Graph" and "Gradient" paragraphs; also notes 20 "Practice task", Worked feedback. Prompt (a) says: "Draw the graph with Reflector distance / m on the vertical axis and Round-trip time / s on the horizontal axis." Canonical answer says: "Plot echo delay vertically against one-way wall distance horizontally." and "Gradient: 85 ÷ 0.5 = 170 s/m. The delay-distance gradient is 2/c. The inferred sound speed is c = 2/gradient, not the gradient itself." Three errors. (i) The model answer plots the opposite axes to the question. (ii) With the question's axes (distance up, time across) the gradient is 85 m / 0.5 s = 170 m/s, whose unit is m/s, not s/m; "170 s/m" is dimensionally wrong (a delay-distance gradient would be 0.5 s / 85 m = 0.00588 s/m = 2/340). (iii) With the question's axes the gradient equals c/2, so c = 2 x gradient = 340 m/s, not 2/gradient (2/170 = 0.0118, which is nonsense). A learner who plots as the question asks and follows the model answer gets c = 0.0118 m/s. The figure notes/assets/practical-6118-20.png follows the prompt (distance vertical), so figure and model answer also contradict each other. Marking line "axis-ratio unit (1)" therefore awards a mark for the wrong unit. Correct version: "Gradient = (85 - 17) / (0.5 - 0.1) = 170 m/s (unit m/s). Gradient = c/2, so c = 2 x 170 = 340 m/s." Either re-write the prompt to plot time (y) against one-way distance (x) with gradient 2/c = 0.00588 s/m (note the prompt's table would then need one-way distance first), or keep the prompt and fix the answer. The conclusion line "use c = 2/gradient" and the notes 20 section "Echo ... slope 2/c" (which is correct for time-vs-distance) must match whichever is kept.

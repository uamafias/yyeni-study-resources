## Reproducing

```bash
harvest discover --seeds _harvest/manifests/seeds-<code>.csv --ext pdf zip --static --out _harvest/manifests/found-<code>.csv
harvest route  _harvest/manifests/found-<code>.csv --rules <rule> --out _harvest/manifests/routed-<code>.csv
harvest tree   _harvest/manifests/routed-<code>.csv
cut -d, -f3 _harvest/manifests/routed-<code>.csv | grep -oE "^[0-9]{4}" | sort | uniq -c
harvest run    _harvest/manifests/qbank-<code>-er.csv            # examiner reports first
harvest run    _harvest/manifests/qbank-<code>-<year>.csv        # one per year, mode=http
harvest run    _harvest/manifests/qbank-<code>-dynamicpapers.csv # gap-fill
harvest run    _harvest/manifests/qbank-9702-w20-dynamicpapers.csv
harvest run    _harvest/manifests/qbank-papacambridge-nov2026.csv
harvest verify "Question Banks/Cambridge Curricula/<tree>" --pattern "<code>_*"
```

0460 (2021–2025) and 9093 were fetched in one combined run, `qbank-remaining-2026-09-28.csv`, so that
pastpapers.co and dynamicpapers.com were fetched in parallel. The per-year manifests still exist for
re-driving.

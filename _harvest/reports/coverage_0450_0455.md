## `_unknown-subject` and foreign-subject contamination

The pastpapers.co page for `business-studies-0450/2020-march` lists **Art & Design (0400)** files
beside the one genuine 0450 file (`0450_m20_er`):

`0400_m20_er` · `0400_m20_gt` · `0400_m20_qp_02` · `0400_m20_ms_1` · `0400_m20_ms_2` · `0400_m20_pm_02_notice`

- Three of these (`er`, `gt`, `qp_02`) matched the rule and routed to the quarantine folder. The
  other three do not follow the Cambridge naming pattern and routed to `_unresolved`.
- **None were fetched.** Following the brief, the discovery manifest was cleaned (rows kept only
  when the filename starts `0450_` or `0455_`), re-routed and re-checked: 0 quarantined, codes
  0450 × 225 and 0455 × 184. The excluded rows are kept in
  `_harvest/manifests/excluded-foreign-0450-0455.csv`.

**The brief's `_unknown-subject` check did not work as written.** The toolkit's router stripped
the leading underscore from every folder name, so the foreign files were filed as
`IGCSE/unknown-subject/`, and `grep -c "_unknown-subject" routed.csv` returned **0** while
three Art & Design rows were present. Only the code-count check caught them. Fixed in the toolkit
(`harvester/route.py`, `_fill`; see the toolkit CHANGELOG, "Unreleased"). The same fix applies to
the 9609 rule, which uses the same default. Re-routing the 9609 corpus gives identical output.

The lookup table also lists other IGCSE codes (0452 Accounting, 0460 Geography, …). A file with
one of those codes would route to that subject's folder, not to the quarantine. The code count,
not the quarantine grep, is the check that catches every foreign file.

## Reproducing

```bash
harvest discover --seeds _harvest/manifests/seeds-0450-0455.csv --ext pdf --static --out _harvest/manifests/found-0450-0455.csv
# keep only 0450_/0455_ rows (see excluded-foreign-0450-0455.csv)
harvest route _harvest/manifests/found-0450-0455.csv --rules cambridge-igcse-question-bank --out _harvest/manifests/routed-0450-0455.csv
harvest tree  _harvest/manifests/routed-0450-0455.csv
cut -d, -f3 _harvest/manifests/routed-0450-0455.csv | grep -oE "^[0-9]{4}" | sort | uniq -c
harvest run   _harvest/manifests/qbank-0450-0455-er.csv          # examiner reports first
harvest run   _harvest/manifests/qbank-<code>-<year>.csv          # 12 manifests, mode=http
harvest route _harvest/manifests/found-dynamicpapers.csv --rules cambridge-igcse-question-bank --out _harvest/manifests/qbank-0450-0455-dynamicpapers.csv
harvest run   _harvest/manifests/qbank-0450-0455-dynamicpapers.csv
harvest verify "Question Banks/Cambridge Curricula/IGCSE" --pattern "04[5][05]_*.pdf"
```
